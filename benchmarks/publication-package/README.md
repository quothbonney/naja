# Preprint evidence package

Start with ../../CLOSEOUT.md (repository root) and ../results/RESULT_FILES.txt. Reports preserve their original paths.

The package includes benchmark drivers, dependency lockfiles, reports, tables, figures, logs and provenance files up to 1 MB each, plus named summary and reaction-diagnostic reports up to 10 MB. included.csv records SHA256 hashes of copied source files. server-only.csv inventories omitted original payloads and their sizes. Raw samples, prepared model arrays, profiler databases, environments, binaries and credentials are not deposited in Git. Original payloads remain under `/mnt/home/jordan+123/history-native-20261015-r5`. Existing absolute paths identify that server snapshot; commands can require path adjustment on another machine.

Historical partial, failed and exploratory runs are retained as evidence; their inclusion does not promote them into final paper results. Historical controller scripts are archived for reproducibility and should not be restarted automatically. No new jobs are launched by packaging.
